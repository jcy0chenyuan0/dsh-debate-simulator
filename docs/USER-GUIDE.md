# 3 分钟上手：辩论模拟插件

目标：**3 分钟内完整跑完一场辩论，并拿到 ZIP 归档 + Word 总结**。
全程不需要写代码，也不需要配置模型（用「演示」模式即可）。

---

## 0:00 — 找到入口

1. 打开 DSH Web GUI（插件装好后刷新一次页面）。
2. 看**左侧边栏**：在「插件管理」「自动化任务」「工具管理」一组里，点 **「辩论模拟」**（⚖️ 天平图标，20px）。
   - 有辩论在跑时，模块页右上显示 **「● 进行中」**，顶部还会带轮次 / 阶段 / 模式标签。
3. 点它 → 主栏整页模块。若上次没跑完，顶部会出现「可恢复」标记和「恢复上一轮」横幅（先不管它）。

> `Esc` 只关闭模块内的「记录 / 归档」弹窗；模块页没有关闭按钮，点侧边栏其他项即可离开，辩论在后台继续。

---

## 0:30 — 填一张启动卡

在启动页填这几项（其余保持默认）：

| 字段 | 建议值（快速体验） | 说明 |
| --- | --- | --- |
| 辩题 | `短视频是否让人更孤独` | 1–200 字，必填 |
| 轮次 | `1` | 1–12；1 轮最快 |
| 气泡秒数 | `1` | 每条发言展示 1 秒 |
| 讨论分钟 | `0.5` | 每方讨论 30 秒（再按「节奏」压缩墙钟） |
| 评委数 | `1` | 1–3 |
| 节奏 | `60` | 讨论阶段墙钟 = 讨论秒数 ÷ 节奏 |
| 模式 | **演示** | 不调用模型，稳定可复现；想试 AI 就切「AI」 |

点 **「开始辩论」**。

> 想换赛制：展开「自定义赛制」JSON。默认已填 14 环节；只有你真的改了内容才会生效。
> 最小可用赛制（2 环节）示例：
>
> ```json
> [
>   { "id": "a", "title": "正方立论", "kind": "speech", "side": "pro", "seat": 1, "seconds": 30 },
>   { "id": "b", "title": "反方质询", "kind": "cross", "side": "con", "seat": 2, "targetSeat": 1, "seconds": 30, "exchanges": 4 }
> ]
> ```

---

## 1:00 — 看辩论台

进入辩论台后，你应该看到：

- **顶部**：辩题、`第 1/1 轮`、环节进度 `3/14`、阶段名、智能体数量；右侧是**计分板**与**计时**
  （总时长 `剩余/总`、正反方分计时、进度条）。
- **左侧正方 4 张头像卡、右侧反方 4 张头像卡**：当前发言者高亮，旁边只有**一个**气泡。
- **讨论阶段**：上方「双方讨论」区**左右两栏同时展示**正反双方的讨论（一开始就同步写入，不是等一方说完）；
  正式发言的气泡下方还有一层灰色 **「💭 内心」**（不对外发言），是该辩手这一回合的内心判断，记录里也能回看。
- 气泡按「气泡秒数」自动消失，然后下一位开口——**同一时刻只会有一条气泡**（严格串行）。
- **底部评委条**：评委头像 + 最新点评 + 实时正反分。
- 每个环节结束，评委会给一次分；计分板与评委条同步刷新。

按钮怎么用：

| 按钮 | 效果 |
| --- | --- |
| 记录 | 打开记录弹窗：按轮次 / 环节分组，可筛选「全部 / 正方 / 反方」 |
| 暂停 | 当前这条气泡播完后挂起（再点「继续」恢复） |
| 跳过 | 立刻结束**当前气泡**的等待，进入下一条 |
| 停止 | 二次确认后结束本轮并清理临时目录（保留已完成轮次的 ZIP） |
| 归档 | 打开归档弹窗：下载每轮 ZIP / 最终 Word / 汇总 Markdown |
| 新辩论 | 回到启动页重新开一场 |

> 期间可以切到侧边栏其他模块——辩论在后台继续，再点「辩论模拟」即可接着看。

---

## 2:30 — 收产物

一轮结束后（模块页顶部显示「已完成」）：

1. 点 **「归档」**：能看到 `第01轮_辩论归档.zip`、`辩论模拟总结_xxx.docx`、`全部轮次汇总.md`，点链接直接下载。
2. 也可以去磁盘找（默认在工作区的 `debate-runs/` 下）：

```text
debate-runs/<runId>/
  第01轮_辩论归档.zip          ← 管理员评论 + 正方/ + 反方/ + 评委/ + README.txt
  辩论模拟总结_<辩题>.docx      ← Word 总结（标题 / 轮次总览 / 教练总结 / 评委评分表）
  全部轮次汇总.md
  rounds-index.json            ← 每轮比分、发言数、评委记录数、ZIP 大小
  state.json / run.json
```

3. ZIP 里的东西：

```text
README.txt            本轮摘要（辩题、比分、环节、发言数、文件清单）
管理员评论.md
正方/草稿纸.md  正方/讨论记录.md  正方/发言记录.md  正方/分析材料.md  正方/总结.md
反方/（同构）
评委/评委记录.md  评委/计分板.md
```

> 注意：轮次归档完成后 `第01轮/` 工作目录会被删除（需求要求「无残留」），内容都在 ZIP 里。
> 轮次进行中还没有 ZIP，等它跑完再看。

## 60 秒速查（赶时间版）

1. 侧边栏「辩论模拟」→ 辩题「短视频是否让人更孤独」→ 轮次 1、气泡 1 秒、讨论 0.5 分钟、评委 1、节奏 60、**演示** → 开始。
2. 看左侧正方 / 右侧反方轮流亮起，一次一条气泡，底部评委给分。
3. 跑完点「归档」→ 下载 `第01轮_辩论归档.zip` 和 `.docx`。

想再快一点：把「自定义赛制」换成上面那个 2 环节 JSON，一场约 1 分钟。

## 常见问题

**Q：为什么一直是「演示」模式，没有真正的 AI 发言？**
A：`AI` 模式需要宿主配置了默认模型；未配置、或单次调用失败/超时，会**逐条回退**演示文本，整场不中断。
想确认当前模式，看模块页顶部的「模式」标签或 `GET /api/dsh-debate/health` 的 `sim.mode`。

**Q：能中途改辩题或换赛制吗？**
A：不能。点「新辩论」重新开始一场（会用你新填的参数）。

**Q：离开「辩论模拟」模块页 / 关掉浏览器，辩论会停吗？**
A：不会，引擎在 Host 侧跑。点侧边栏「辩论模拟」回到模块页即可继续看。若整个 DSH 进程中断，下次进入模块页会出现「可恢复」与「恢复上一轮」，
点它从断点继续（`state.json` 每 ≤250ms 防抖落盘）。

**Q：产物在哪里？能改目录吗？**
A：默认 `<当前工作区>/debate-runs/<runId>/`；在插件配置里设 `runsDir` 可改根目录（见 README「配置项」）。

**Q：为什么辩手看不到计分板和评委点评？**
A：这是刻意的权限隔离：辩手上下文不含 `scoreboard` / 评委记录 / 对方草稿，评委、教练、管理员才看全部。
详见 README「权限隔离」。
